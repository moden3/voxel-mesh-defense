# Voxel Mesh Defense

Voxel Mesh Defenseは、未知の地下空間を掘り進め、高低差と物理法則（背圧・重力）を利用したエネルギー網を構築し、深淵から迫る敵を自律型スウォームと空間制圧兵器で迎え撃つ「3D多層・創発型オートメーション防衛ゲーム」です。

## 概要 (Overview)

プレイヤーは地下空間の壁を掘り抜き、資源を獲得しながら巨大な防衛網を構築します。
UIから細かな設定を行うのではなく、「パイプの太さ・分岐・高低差」といった**物理的な配線構造**そのもので、エネルギーのルーティングや優先順位を制御します。
さらに、自分が掘り抜いた空洞がそのまま「深淵から迫る敵の侵攻ルート」になるというジレンマのなか、最適な空間制圧兵器を配置し、コアを守り抜く必要があります。

## 主要機能 (Key Features)

- **空間トポロジーによる創発的ルーティング**: セル・オートマトンを用いた軽量な疑似流体計算により、背圧や重力が表現されるエネルギー網。
- **リスクとリターンの掘削**: 掘れば掘るほど資源や強力なアーティファクトが見つかるが、同時に敵が這い上がってくる道を作ることになる。
- **自律型スウォーム**: プレイヤーは直接建築せず、マーカーを置くだけ。無数のドローンがインフラ（エネルギー供給網）に依存しながらフローフィールドを用いて最適経路で移動し、タスクを完遂する。
- **3D空間防衛**: ボクセル地形の形状に合わせてキルゾーンを設定する空間制圧型のタワーディフェンス。

## 技術スタック (Tech Stack)

- 言語: [Rust](https://www.rust-lang.org/)
- ゲームエンジン: [Bevy Engine](https://bevyengine.org/)
- アーキテクチャ: Entity Component System (ECS) によるデータ指向設計

## 実行方法 (How to Run)

Rust開発環境（`cargo`）がインストールされている必要があります。

```bash
# プロジェクトのクローン
git clone https://github.com/your-username/voxel-mesh-defense.git
cd voxel-mesh-defense

# 実行
cargo run --release
```

※ 初回ビルド時はBevyエンジンの依存クレートコンパイルに時間がかかる場合があります。
