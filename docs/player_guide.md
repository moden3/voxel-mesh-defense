# プレイヤーガイド: Voxel Mesh Defense

ようこそ、地下司令官。
このマニュアルは、地下深くに拠点を築き、迫りくる深淵の脅威からコアを防衛するための基本知識をまとめたものです。

---

## 1. ゲームの目的

あなたの目的は、地下空間を掘削して未知のエネルギー源（地熱や鉱脈）を探し出し、それらを自律型ワーカーを使って「コア」までつなげることです。
しかし、深く掘り進めるほど「深淵に潜む敵」があなたを感知し、掘削した空洞を伝ってコアへ侵攻してきます。
複雑な地形を活かしたエネルギー網と防衛網を構築し、最深部からの脅威を退けてください。

## 2. 物理的な配線による「創発的ルーティング」

このゲームに複雑な「設定画面」はありません。パイプの設置の仕方（トポロジー）自体が、エネルギーの配分を決定します。

- **重力の法則**: エネルギーは「より低い場所（下り坂）」へ優先して流れます。上層へ引き上げるには、一定間隔で「ポンプ」を設置し、コストを支払う必要があります。
- **背圧（逆流）**: 末端の施設がエネルギーを消費しきれずパイプが詰まると、エネルギーは逆流したり、別の分岐ルートへ溢れ出したりします。
- **配管のコツ**: パイプを太く並行に並べれば大容量の輸送が可能ですが、敵に破壊されるリスクも高まります。細く分散させるか、太い幹線を作るかはあなた次第です。

## 3. 掘削のリスクとリターン

空間の壁（ボクセル）をクリックして「掘削マーカー」を置くことで、ワーカーたちが壁を壊し始めます。

- **リターン**: 新たな資源、空間、強力な恩恵をもたらす「遺物」が見つかります。
- **リスク**: 掘った穴はそのまま「敵の通り道」になります。不用意に拠点へ直結するトンネルを掘ると、防衛が間に合わずにコアが陥落します。意図的に「迂回路」を作り、そこに防衛兵器を集中させる（キルハウスを作る）のがセオリーです。

## 4. 自律型スウォーム（ワーカー）の使役

プレイヤーは直接ブロックを壊したり置いたりしません。
空間に「指示マーカー」を配置すると、コアからワーカー（小型ドローン）が出撃して作業を行います。

- **エネルギー依存**: ワーカー自身もエネルギーを消費します。エネルギー網（パイプライン）の周囲に展開される「充電エリア」から離れすぎると活動できません。遠くを掘削するには、まずパイプを伸ばしてインフラを整備する必要があります。
- **群れの最適化**: 指示を出しすぎるとワーカーの経路が混雑します。通路を広く保つことが効率化の鍵です。

## 5. 防衛と敵の「学習」

地下深部からスポーンする敵は、単にコアへ向かうだけではありません。

- **空間防衛**: 防衛施設（タワー）は、特定の方向への射程や、周囲の球状空間への攻撃判定を持ちます。狭い通路や縦穴（立坑）に設置して、弾幕を張りましょう。
- **敵の壁掘削**: 敵は賢く、防衛施設が密集している「キルゾーン」を避けるようになります。あえて壁を壊し、新たなバイパス（抜け道）を作ってくるため、絶対に安全な壁は存在しません。「壊されやすい壁」を補強するか、あえて突破させて地雷原に誘い込む戦略が必要です。
