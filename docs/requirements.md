# 1. プロジェクト概要
本作は「3D多層・創発型オートメーション防衛ゲーム」です。未知の地下空間を掘り進め、高低差と物理法則（背圧・重力）を利用したエネルギー網を構築し、深淵から迫る敵を自律型スウォームと空間制圧兵器で迎え撃つシミュレーションゲームです。「物理的な配線構造による創発的ルーティング」と「掘削によるリスクとリターンのジレンマ」をコアとします。

# 2. ターゲットユーザー
- FactorioやSatisfactoryなどの自動化・ロジスティクス構築ゲームのファン
- Minecraftなどのボクセル空間での自由な建築や発掘が好きなプレイヤー
- RimWorldやDwarf Fortressなどのコロニーシミュレーションで、創発的なトラブルシューティングを楽しむ層

# 3. 機能要件 (Functional Requirements)
- **空間トポロジーによる創発的ルーティング**
  - ユーザーとして、パイプを配置することでエネルギー網を構築できる。
  - ユーザーとして、パイプの太さ、分岐、高低差を物理的に調整することで、UIによる設定なしでエネルギーの流量制限、背圧（逆流・滞留）、重力（下方向への優先）を制御できる。
- **掘削と探索（Risk & Reward Exploration）**
  - ユーザーとして、ボクセル空間（有限マップ）の壁を掘り抜くことで、未知の鉱脈や地下空洞を発見できる。
  - ユーザーとして、掘り抜いた空間が敵の侵攻ルート（道）となるリスクを管理・防衛する必要がある。
- **空間制圧型の3D防衛（Spatial Defense）**
  - ユーザーとして、3D空間に影響範囲（キルゾーン）を持つ防衛施設を設置できる。
  - ユーザーとして、複雑な地下通路の形状に合わせて防衛網を展開し、自動迎撃システムを構築できる。
- **自律型スウォームとインフラ（Swarm Orchestration）**
  - ユーザーとして、空間に「掘削」「建設」のマーカーを置くことで、自律型のドローン（ワーカー）に作業を指示できる。
  - ワーカーとして、エネルギー供給範囲（インフラノード）に依存して活動し、最適化された経路探索（フローフィールド等）で作業を完遂できる。
- **敵の学習と経路破壊**
  - 敵として、プレイヤーの防衛網（キルゾーン）を避け、壁を掘削して新たなバイパスを開拓しながらコアへ侵攻できる。

# 4. 非機能要件 (Non-Functional Requirements)
- **パフォーマンス**: 数千単位のワーカーやエネルギー流（セル・オートマトン）が動作してもスムーズなフレームレート（60FPS）を維持できること（データ指向設計の適用）。
- **グラフィックス**: ボクセルベースの3Dレンダリング。
- **プラットフォーム**: PC（Windows等）。
- **操作性**: 直感的な3Dフライカメラ操作と、マウスによる正確な空間指定（ピッキング）。

# 5. 制約事項
- **技術スタック**: Rust言語およびゲームエンジンBevyを使用する。
- **物理エンジン設計**: 汎用の3D剛体物理エンジン（Rapier等）は使用せず、AABBによる衝突判定と、セル・オートマトン、フローフィールドなどの専用アルゴリズムを自作して処理負荷を抑える。
- **スコープ（保留機能）**: 「熱と冷却の概念」および「遺物による局所的な物理法則のハック」は初期バージョン（MVP）には含めず、将来の拡張機能とする。
